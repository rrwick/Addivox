# Demo version

<p align="center"><img src="../assets/demo-ui.png" alt="Addivox demo-mode UI" class="float-right" style="max-width: 50%; width: 250px;"></p>

The demo version of Addivox is available for the same app and plugin formats as the full version of Addivox.

It has full functionality except:

- It will only play white-key notes (e.g. C major).
- Transposition is disabled.

Before purchasing Addivox, I would encourage you to try the demo version. This will let you test whether it works on your computer and DAW, and whether you like the sound.

You can download the demo version of Addivox from the [GitHub releases page](https://github.com/rrwick/Addivox/releases/latest), and here are direct links to the zip files:<br>
[`AddivoxDemo_v1.2.0_macOS.zip`](https://github.com/rrwick/Addivox/releases/download/v1.2.0/AddivoxDemo_v1.2.0_macOS.zip)<br>
[`AddivoxDemo_v1.2.0_Windows.zip`](https://github.com/rrwick/Addivox/releases/download/v1.2.0/AddivoxDemo_v1.2.0_Windows.zip)

After downloading, see the [Installation – macOS](installation_macos.md) or [Installation – Windows](installation_windows.md) page for instructions on how to install the demo version of Addivox.


### After purchasing

The demo version is named `AddivoxDemo`, so it can be installed alongside the full version of `Addivox` without the two conflicting. After buying the full version, however, most users will probably want to uninstall the demo version.

To keep any custom patches you created with the demo version, copy them from the demo patch folder to the full-version patch folder. See [Patches](patches.md#custom-patches) for the patch folder locations.
